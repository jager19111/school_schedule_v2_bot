# Шпаргалка: отображение изменений расписания (ученик / учитель)

Референс для всех рендеров (полное расписание, дневная сводка изменений, утренняя сводка, постер-картинка). Собрано из решений, принятых по ходу разработки бота. Если меняете форматирование в одном шаблоне — сверяйтесь с этим документом, чтобы не разъехаться с остальными.

---

## 0. Базовые принципы

1. **Иконка + зачёркивание = статус. Слова «ОТМЕНА»/«Отменено» нигде не пишем.** Эмодзи и `<s>текст</s>` дают полное понимание того, что урок отменён — дублирующее слово только шумит.
2. **`➔` — только между «было» и «стало».** Внутри одной стороны (или там, где сравнивать не с чем) — разделитель `·`.
3. **Каждое поле показывается только если оно реально изменилось.** Не changed → не пишем, даже если оно есть в данных. Единственное исключение — «контекст», который у каждой роли показывается всегда (см. п.1 таблицы ниже), потому что без него запись неоднозначна.
4. **Один канал = один смысл.** Цвет/зачёркивание не должны требовать от пользователя знания вашей внутренней конвенции без иконки-дублёра.
5. **Список изменений показывает только то, что изменилось.** Уроки без пометки `is_exchange`/`is_cancelled` в дневную сводку вообще не попадают — они и так видны в обычном расписании.

### Иконки (единый словарь по всем поверхностям)
| Иконка | Значение |
|---|---|
| 📚 | обычный урок, без изменений |
| 🔄 | предмет заменён (замена урока целиком) |
| 🔁 | предмет тот же, поменялось что-то второстепенное (кабинет/учитель) |
| 🚫 | урок отменён |
| ➕ | добавлен новый урок (окна не было — появился урок) |
| 🎨 | доп. занятие (не влияет на статус-логику ниже) |

> ⚠️ **Известная нестыковка, которую стоит починить**: в утренней сводке отмена помечена ❌, а в дневной сводке изменений — 🚫. Разные иконки для одного и того же статуса на разных поверхностях — стоит унифицировать на 🚫 (более нейтральная, ❌ визуально ближе к «ошибке/сбою», а не к «урока не будет»).

## 1. Приоритет полей по ролям — главная идея документа

| Поле | Ученик / родитель | Учитель |
|---|---|---|
| **Предмет** | 🥇 Главное — что за урок | 🥉 Второстепенное — меняется редко, показываем только если реально изменился |
| **Кабинет** | 🥈 Важное — куда идти | 🥈 Важное — куда идти |
| **Класс + группа** | ⚪ Не нужно — ученик и так в своём классе | 🥇 Главное — какой класс/группа, у кого урок |
| **Преподаватель** | 🥉 Второстепенное — пишем, только если это единственное изменение | ⚪ Почти не нужно — учитель видит своё расписание от своего лица, имя другого педагога не носитель смысла |

**Почему так.** Ученик всегда в одном и том же классе — контекст «какой класс» ему не нужен, а вот «куда идти» и «что за урок» — единственное, ради чего он вообще открывает уведомление. У учителя наоборот: предмет у него почти никогда не «плавает» (математик как вёл геометрию, так и ведёт), а вот класс/группа/кабинет меняются постоянно из-за замен и подмен коллег — это и есть та информация, ради которой он открывает уведомление.

## 2. Разбор всех кейсов

Каждый кейс — с примером в реальной разметке (как в Telegram HTML-режиме), отдельно для ученика и для учителя.

### 2.1 Полная замена: предмет + кабинет + преподаватель

Данные: `subject`, `room`, `teacher` — все три отличаются от исходных.

**Ученик** (иконка 🔄, преподаватель не пишем — он второстепенен при полной замене):
```
🔄 1*. Математика [109] ➔ Физика [230]
```

**Учитель** (иконка 🔄, класс/группа — контекст всегда; предмет диффуем, преподаватель другого человека не пишем — учителю не важно, кто вёл этот урок раньше):
```
🔄 1*. 6а · Геометрия [201] ➔ Алгебра [305]
```

> Обратите внимание: у ученика в примере зачёркнутого «было» нет специально — если в вашем шаблоне принято подчёркивать «было→стало» явно, добавьте `<s>Математика [109]</s> ➔` перед новым значением. Главное правило раздела 0.2 не меняется: `➔` только между сторонами.

---

### 2.2 Замена кабинета (предмет и преподаватель те же)

Данные: только `room` отличается.

**Ученик**:
```
🔁 2*. Математика <s>[109]</s> ➔ [230]
```

**Учитель** (контекст класс/группа всегда виден, дальше — диф кабинета):
```
🔁 2*. 6а <s>[109]</s> ➔ [230]
```
Если у учителя ещё и предмет тот же, но заметно отличается от привычного — можно опустить сам предмет вовсе (он избыточен), это и показано выше: класс — главное, предмет для учителя вторичен даже в «спокойном» кейсе.

---

### 2.3 Замена преподавателя (предмет и кабинет те же)

Данные: только `teacher` отличается.

**Ученик** — предмет писать не нужно (он не менялся), это чисто информационная строка «кто ведёт»:
```
🔁 3*. (Иванова И.И. ➔ Петров П.П.)
```

**Учитель** — этот кейс для самого учителя почти не встречается в смысловом виде (учитель не «узнаёт», что его самого заменили, из своей же ленты изменений другим человеком за него). Если такая запись всё же попадает в сводку (например, администратору-наблюдателю), формат такой же, как у ученика, но с контекстом класса:
```
🔁 3*. 6а (Иванова И.И. ➔ Петров П.П.)
```

---

### 2.4 Замена кабинета И преподавателя одновременно (предмет тот же)

Данные: `room` и `teacher` отличаются, `subject` — нет.

**Ученик**:
```
🔁 4*. Математика (<s>[109] Иванова И.И.</s> ➔ [230] Петров П.П.)
```

**Учитель**:
```
🔁 4*. 6а (<s>[109] Иванова И.И.</s> ➔ [230] Петров П.П.)
```

> Важно не путать этот кейс с 2.2/2.3: раз меняются оба поля сразу, их нужно показывать **вместе, одной парой «было→стало»**, а не двумя отдельными строками — иначе пользователь не поймёт, относится ли новый кабинет к новому или к старому учителю.

---

### 2.5 Замена/отмена у ОДНОЙ из подгрупп (предмет, кабинет, учитель или что-то одно)

Урок разбит на подгруппы (например, «Труд(технология)» — мальчики/девочки). Меняется только одна подгруппа, вторая остаётся как была — **и поэтому вторую в сводку изменений не включаем вовсе**, она не incremented в `is_exchange`/`is_cancelled`, значит для пользователя и так видна нормальной в расписании.

**Ученик**, поменялся кабинет только у группы 2:
```
🔁 5*.
  └ 👥 Группа 2: <s>[201]</s> ➔ [305]
```

**Ученик**, отменена только группа 1 (группа 2 идёт как обычно):
```
🚫 5*.
  └ 👥 Группа 1: Физкультура
```
(без второй строки — группа 2 не менялась, её в сводке нет)

**Учитель** — «у преподавателя никогда не бывает уроков подгруппами», этот кейс для учителя структурно не возникает: учитель ведёт либо весь урок, либо не ведёт его вовсе в этом слоте. Формат дерева `├/└` в шаблоне для учителя остаётся зарезервирован на случай аномалий в данных, но в норме учитель всегда получает одну строку на урок (см. 2.1–2.4).

---

### 2.6 Отмена у ОБЕИХ подгрупп (весь предмет снят)

Данные: обе строки урока имеют `is_cancelled=1`.

Когда отменены **все** подгруппы слота — это семантически то же самое, что обычная отмена целого урока (см. правило «поглощения» в `collector.py`: если для слота есть решение на уровне «Весь класс», оно поглощает подгрупповой шум; если такого решения нет, но отменены все существующие в слоте строки — они всё равно эквивалентны полной отмене). Рендерим **без дерева**, одной строкой, без деления по группам — пользователю не нужно знать, что технически это были две записи в БД:

**Ученик**:
```
🚫 6*. Физкультура
```

**Учитель**:
```
🚫 6*. 6а · Физкультура
```

---

### 2.7 Добавление нового урока вместо окна

Данные: строки без `original_subject_name` (в базе не было исходного урока на этом месте).

**Ученик**:
```
➕ 8*. ➔ Консультация [312]
```

**Учитель**:
```
➕ 8*. 6а ➔ Консультация [312]
```

Ключевое отличие от остальных кейсов — **нет левой (зачёркнутой) стороны вообще**, даже тире-заглушки: сравнивать не с чем, это не замена, а появление. Единственная иконка, для которой в шаблоне не должно быть ветки `<s>—</s> ➔`.

| # | Кейс | Иконка | Ученик показывает | Учитель показывает |
|---|---|---|---|---|
| 2.1 | Полная замена (предмет+кабинет+учитель) | 🔄 | Предмет, Кабинет | Класс/Группа, Предмет |
| 2.2 | Только кабинет | 🔁 | Предмет + диф кабинета | Класс/Группа + диф кабинета |

## 4. Порядковый номер урока. 

Для ученика и родителя используется порядковый номер урока с учетом смены `first.display_num`
Для учителя используется абсолютный порядковый номер урока (от 1 до 12) и не учитывает смену `first.lesson_num`
